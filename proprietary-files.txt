# Proprietary files for the iKKO MindOne (MT6789 / Helio G99).
#
# Every entry was verified to exist, at the exact source path given, in a dump of this device's
# own vendor and system_ext partitions: the images were mounted read-only and the file lists
# compared programmatically, not by eye. Anything that could not be found on the device was
# dropped rather than carried on faith -- a listed file that does not exist fails the build late
# and for a reason that is hard to read.
#
# The camera entries are specific to this phone. The MindOne carries an IMX766, so its sensor
# blobs are listed and no other sensor's are.
#
# 🔴 Scope: vendor and system_ext only. product and system have not been cross-checked yet
# (product alone is ~3 GiB and is mostly AOSP app and framework content, so the density of
# proprietary files there is low). Firmware follows a separate convention
# (proprietary-firmware.txt) and is not covered here either.
#
# Nothing in this list is committed to this repository. extract-files.py pulls these from your
# own device -- see docs/BLOBS.md.

# MINDONE 11.09: ten MediaTek vendor audio decoders are DISABLED (F4154).
# They are built for stock Android 15 and inherit from SimpleC2Component, whose implementation
# for us comes from Android 16 sources (our libcodec2_soft_common.so is 483268 bytes vs.
# 117216 for the stock one). The object layout differs, so on destruction Scudo catches a
# pointer mismatch against the start of the block, and the codec service crashes on every boot -
# ten tombstones from 09.09 to 11.09, the signature does not change.
# Cost of disabling: no APE or ALAC decoders. MP3, AAC, FLAC, Opus, Vorbis are covered by
# Android's own decoders. Restore the lines if the crashes do not stop.
